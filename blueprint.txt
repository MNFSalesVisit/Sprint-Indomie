SALES VISIT SYSTEM (BLUEPRINT)
The Sales Visit System is a role-based ERP platform designed to manage field sales operations, stock movements, shop visits, uplift approvals, and performance analytics.
The system operates through three main modules:
1.	Super Admin Module – System governance and configuration
2.	Admin Module – Operational management and approvals
3.	Salesperson Module (User Portal) – Field sales execution
The platform enforces strict role-based access control (RBAC) to ensure users only access features relevant to their responsibilities.

SALES VISIT FORM
All fields are mandatory.
________________________________________
Field 1: Region
User selects region.

Example:
•	Mombasa → only Mombasa subregions
•	Nairobi → only Nairobi subregions
________________________________________

Field 2: Shop Name
Scenario 1: New Shop
User registers shop using format:
Shop Name - Location
Example:
Abaa Shop - VOK
System automatically stores:
•	Shop name
•	GPS coordinates
The shop is then auto-selected.
________________________________________
Scenario 2: Existing Shop
User searches by typing letters.
Only shops within the selected region appear.
________________________________________
Field 3: Stock Position
User enters current stock at shop per SKU.
Features:
•	Numeric input only
•	
o	/ – buttons
•	Stock value overwrites previous value
________________________________________
Field 4: Sold?
User selects:
•	Yes
•	No
________________________________________
If YES
User enters quantity sold per SKU.
System automatically:
•	Deducts sold quantity from user stock balance
Restrictions
•	Cannot sell if stock balance = 0
•	Cannot exceed available stock
Error message:
"You cannot sell. Your stock balance is 0. Uplift first."
________________________________________
If NO

•	Financial constraints
•	Stock available
•	Other
If Other, user enters custom reason.
________________________________________

UPLIFT LOGIC (STOCK CONTROL SYSTEM)
The system enforces strict stock control.
________________________________________
1. Stock Balance Before Uplift
If stock balance = 0
User cannot sell any SKU.
________________________________________
2. Uplift Submission
When uplift is submitted:
•	Status = Pending Approval
•	Stock balance remains unchanged
________________________________________
3. Uplift Approval
When admin approves uplift:
System automatically:
•	Adds uplift cartons to stock balance
Updated stock appears on dashboard stock box.
________________________________________
If Uplift is Rejected
Stock balance remains unchanged.
Rejection reason appears in Uplift Status Box.
________________________________________
4. Sales Restrictions
Sales cannot exceed available stock.
Error message:
"You cannot sell more than your available stock balance. Please uplift stock first."
________________________________________
5. Stock Deduction After Sale
After a sale is recorded:
•	Sold quantity is deducted
•	Updated balance appears immediately.
________________________________________
Example Scenario
1.	Salesperson stock balance = 0 cartons
2.	Salesperson requests uplift for 20 cartons
3.	Status = Pending
4.	Admin approves uplift
5.	Stock balance becomes 20 cartons
6.	Salesperson can sell up to 20 cartons only
